CHATZY - FULL-STACK MESSAGING APPLICATION SETUP

PROJECT STRUCTURE:
- /server - Node.js/Express backend with Socket.IO
- /web - React + Vite web application
- /mobile - React Native + Expo mobile application

BACKEND SETUP:
1. Navigate to /server directory
2. Copy .env.example to .env and configure:
   - MONGODB_URI: MongoDB connection string (use MongoDB Atlas for production)
   - JWT_SECRET: Secure random string for token signing
   - PORT: Server port (default 5000)
   - NODE_ENV: Set to "production"
   - FRONTEND_URL: Production web URL (https://yourdomain.com)
   - MOBILE_URL: Expo app URL (exp://yourdomain.com)
   - API_URL: Production API URL (https://yourdomain.com/api)
   - SOCKET_URL: Production socket URL (https://yourdomain.com)

3. Install dependencies: npm install
4. Start server: npm start

DEPLOYMENT (Backend):
- Use Railway, Render, Fly.io, or similar service
- Set environment variables in deployment platform
- MongoDB Atlas for database
- Server will automatically use HTTPS with your custom domain

WEB SETUP:
1. Navigate to /web directory
2. Copy .env.example to .env and configure:
   - VITE_API_URL: Production API URL (https://yourdomain.com/api)
   - VITE_SOCKET_URL: Production socket URL (https://yourdomain.com)

3. Install dependencies: npm install
4. Development: npm run dev
5. Build: npm run build

DEPLOYMENT (Web):
- Build: npm run build
- Deploy to Netlify, Vercel, or similar
- Point to your backend API and Socket.IO URLs

MOBILE SETUP:
1. Navigate to /mobile directory
2. Copy .env.example to .env and configure like web
3. Install dependencies: npm install
4. Install Expo CLI: npm install -g eas-cli
5. Start development: expo start
6. Run on Android/iOS from Expo Go or build for production
