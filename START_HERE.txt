WHAT IS CHATZY?

Chatzy is a production-ready, real-time messaging platform featuring:
- Private and group messaging
- Real-time notifications
- File sharing
- Friend management
- User blocking
- 100+ fully implemented API endpoints
- Responsive web interface
- Native mobile app
